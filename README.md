# Saya no Uta для PSP (VNDS-интерпретатор)

Неофициальный фанатский проект: движок для запуска визуальных новелл в формате **VNDS** на **PSP** с кастомной прошивкой, доработанный так, чтобы на нём можно было пройти *Saya no Uta* (沙耶の唄) на русском языке — с кириллицей, ветвлением сюжета, музыкой и обычными сохранениями PSP.

> **English:** a modified fork of [VNPSP](https://github.com/liclac/VNPSP) — a VNDS visual-novel interpreter for the Sony PSP. Added: Cyrillic text (CP1251 bitmap font), branching scripts (`jump`, `choice`, nested `if/fi`, variables), ATRAC3 music, native PSP save slots, pre-scaled assets. **No game data is included** — you need your own copy of the novel.

## ⚠️ Важно

- Новелла предназначена для **взрослых (18+)**.
- Проект не связан с разработчиками и издателями игры. Если игра вам понравилась — поддержите авторов покупкой.

## Что умеет

Относительно исходного VNPSP добавлено:

- **Кириллица.** Текст в скриптах (UTF-8) перекодируется в CP1251 и рисуется собственным растровым шрифтом `cyr.oft` (системный шрифт PSP кириллицу не поддерживает).
- **Команды VNDS:** `jump`, `choice`, `if` / `fi` (с вложенностью; операторы `==  !=  <=  >=  <  >`), `setvar`, `gsetvar`, `endscript`, `music`, а также расширение `loadgame`. Команды `sound` и `delay` читаются, но пока игнорируются.
- **Музыка ATRAC3 (`.at3`)** в отдельном потоке, с зацикливанием. Соответствие «имя трека в скрипте → файл» задаётся в `music/music_map.txt`.
- **Сохранения как у обычных игр PSP:** стандартное системное окно, 10 слотов, файлы в `ms0:/PSP/SAVEDATA/`, видны в *Игры → Сохранённые данные*.
- **Текст постранично:** новая порция заменяет прежнюю, при смене фона экран очищается; под текстом полупрозрачная панель.
- **Нормальные спрайты:** корректная прозрачность, координаты `setimg` в системе 256×192 (как в VNDS для DS), масштаб по высоте экрана.
- **Определение формата картинок по содержимому** (PNG/JPEG), а не по расширению — в некоторых пакетах PNG лежат под именем `.jpg`.
- **Запуск как обычной игры:** если установлена одна новелла, меню выбора пропускается.
- Исправления совместимости с современным `pspdev` (см. раздел «Сборка»).

## Требования

- PSP с кастомной прошивкой ARK-4 (проверялось на **PSP-3004, CFW 6.61**).

## Установка

1. Роспакуйте архив в папку Game на псп.

```
ms0:/PSP/GAME/SayaNoUta/
├── EBOOT.PBP
├── cyr.oft
├── save_icon.png            (необязательно: иконка для сохранений)
└── novels/
    └── <название новеллы>/
        ├── info.txt         title=Название
        ├── img.ini          width=256 / height=192
        ├── script/          *.scr
        ├── CG/              фоны, 480×272, JPEG (baseline)
        ├── CGAlt/           спрайты, PNG с прозрачностью, высота 272
        └── music/           *.at3 и music_map.txt
```

Пример `music_map.txt` (строки вида `имя_в_скрипте=файл`):

```
s01=01.at3
s02=02.at3
```

## Подготовка ресурсов

PSP не тянет большие картинки, поэтому ресурсы нужно заранее уменьшить:

- **Фоны** — до 480×272, обычный (не progressive) JPEG. Картинки 4:3 лучше вписывать с чёрными полями.
- **Спрайты** — PNG с альфа-каналом, масштаб по высоте до 272 пикселей с сохранением пропорций.
- **Музыка** — ATRAC3 (`.at3`), например 66 kbps. Конвертируется официальными инструментами для PSP.
- В `img.ini` ставьте `width=256`, `height=192`: позиции `setimg` в скриптах VNDS заданы в этих единицах.

> Скрипт автоматической подготовки ресурсов — в `tools/` (если его там нет, значит ещё не добавлен).

## Управление

| Кнопка | Действие |
|---|---|
| ✕ | дальше по тексту / подтвердить |
| ↑ / ↓ | выбор варианта |
| Start | меню паузы: продолжить, сохранить, загрузить, выход |
| ○ | закрыть меню паузы |

На титульном экране есть пункт «Загрузить», чтобы не заходить в игру ради загрузки.

## Сборка

```bash
git clone --recursive https://github.com/<ваш-ник>/<репозиторий>.git
cd <репозиторий>
export PSPDEV=/путь/к/pspdev
export PATH=$PATH:$PSPDEV/bin
make
```

Получится `EBOOT.PBP`. Для текущего `pspdev` в код внесены правки: заголовок `sys/select.h` вместо `sys/fd_set.h` в OSLib, `PSP_HEAP_SIZE_KB(-1)` вместо `PSP_HEAP_SIZE_MAX()` и линковка с `-lpspatrac3`.

Файлы `ICON0.png`, `PIC1.png` и `SND0.AT3` (иконка, фон и звук в меню PSP) в репозитории нейтральные — подставьте свои.

## Известные ограничения

- Нет озвучки и звуковых эффектов (команда `sound` игнорируется), нет задержек и анимированных переходов.
- Поддерживается только подмножество команд VNDS, достаточное для этой новеллы.
- Шрифт содержит кириллицу и латиницу (CP1251), японские иероглифы не отображаются.
- Если новый спрайт ставится на место старого без смены фона, возможно «двоение» краёв (в этой новелле — в трёх местах).
- Проект проверялся на одной модели консоли и прошивке.
